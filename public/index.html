Pertanyaan umum

Berapa lama top up diproses?

Pesanan diproses admin setelah pembayaran diverifikasi. Kirim bukti bayar lewat WhatsApp agar lebih cepat.

Salah memasukkan ID, bagaimana?

Pastikan ID dan server benar sebelum membayar. Top up ke ID yang salah tidak bisa dibatalkan.

Bagaimana cek status pesanan?

Gunakan kode pembelian pada menu Cek Pesanan. Riwayat hanya tersimpan di perangkat yang dipakai memesan, atau hubungi admin dengan kode Anda.
